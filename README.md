# G.Scacco

Sito statico realizzato con [Hugo](https://gohugo.io/). Il tema è incluso nei template e negli stili del repository, quindi non servono temi o dipendenze esterne.

## Avvio locale

```sh
hugo server --buildDrafts
```

## Generazione

```sh
hugo
```

I file pubblicabili vengono creati nella cartella `public/`. I nuovi articoli possono essere creati con `hugo new content/post/titolo.md`; per impostazione predefinita sono bozze.
